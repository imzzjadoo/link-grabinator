# Link Grabinator

Download videos and audio from YouTube, Facebook, Instagram, TikTok, X and direct file links, right on your Android phone.

## Download

👉 **[Get the latest version](https://github.com/imzzjadoo/link-grabinator/releases/latest)**

Most phones should use **LinkGrabinator-arm64.apk** (smaller). If it won't install, use **LinkGrabinator-universal.apk**.

## Features

- Paste a link and choose MP3 or M4A audio, or video in the quality you want
- Look up a whole playlist, pick items or select all, and batch download
- Sign in to YouTube, Instagram, Facebook, TikTok and X for private or restricted posts
- Choose your own download folder
- One-tap "Update engine" to keep downloads working
- Spotify playlists show the track list (Spotify audio itself can't be downloaded)

## How to install

1. Download the APK on your Android phone.
2. Open it. If asked, allow your browser or file manager to "install unknown apps".
3. Tap **Install**.
